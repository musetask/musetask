## Tasks for muse

- there would be a directory for tasks like `2026-10` in the format year-month
- tasks in the directory would be file named `01task-fix-the-repo` in the format of $number"task"-"task name"
- and the file content would be a task
- muse should create a new file named `01finished-fix-the-repo` in the same directory and record the process and result of the task
